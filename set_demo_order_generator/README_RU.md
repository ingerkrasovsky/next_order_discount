# Demo Order Generator

Отдельный демо-модуль для PrestaShop 8.1/9. Он добавляет страницу **Каталог → Demo Order Generator** и создаёт настоящий заказ через `PaymentModule::validateOrder()`.

Благодаря штатному процессу создания заказа модуль `set_next_order_discount` получает обычные хуки, сопоставляет заказ с активными правилами, создаёт купон и отправляет письмо.

## Поля формы

- email, имя и фамилия клиента;
- точная итоговая сумма заказа с налогами и доставкой;
- товар (его категории и производитель участвуют в выборе правила);
- валюта;
- страна доставки;
- группа клиента;
- язык письма;
- статус заказа.

Если клиент с таким email уже существует, он используется повторно. Поэтому повторное создание заказа на тот же email позволяет тестировать условия по количеству заказов.

После успешного создания модуль сохраняет историю в таблице `PREFIX_sdog_usage`: email, имя, идентификаторы клиента и заказа, сумму, валюту, купон и дату. Последние 100 записей текущего магазина отображаются только через **Менеджер модулей → Demo Order Generator → Настроить**. На странице генератора в разделе «Каталог» история не показывается. Доступ можно ограничить правами сотрудника на конфигурацию модулей, оставив ему только право на вкладку генератора.

Для получения точной суммы в корзину добавляется нужное количество выбранного товара и временное правило корзины, уменьшающее итог до введённого значения. После создания заказа временное правило удаляется. Остатки товара восстанавливаются.

## Установка

1. Установить и включить `set_next_order_discount`.
2. Убедиться, что включён один из модулей оплаты: `ps_wirepayment`, `ps_checkpayment` или `ps_cashondelivery`.
3. Упаковать каталог `set_demo_order_generator` в ZIP либо скопировать его в `/modules/`.
4. Установить модуль через менеджер модулей.
5. Открыть **Каталог → Demo Order Generator**.

Созданные тестовые заказы и клиенты при удалении модуля не удаляются.
Таблица истории использования при удалении модуля удаляется.

При обновлении с версии 1.0.0 до 1.1.0 таблица истории создаётся автоматически скриптом `upgrade/upgrade-1.1.0.php`.
