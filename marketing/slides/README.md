# Слайды 2000×2000 для Next Order Discount

Набор повторяет структуру `loyalty_milestones/marketing/slides`: 4 смысловых баннера и 10 экранов модуля, всего 14 слайдов.

## Состав

1. Обложка: автоматический купон после покупки.
2. Dashboard и воронка купонов.
3. Таблица правил.
4. Основные параметры правила.
5. Баннер о таргетинге.
6. Условия правила.
7. Формат промокода.
8. Баннер о письмах.
9. Редактор писем.
10. Предпросмотр письма.
11. Баннер об автоматизации.
12. Список купонов.
13. Cron/Tools.
14. Общие настройки.

## Файлы

- `slide_builder.html` — визуальный HTML-билдер на русском языке.
- `translations.js` — единый источник текстов.
- `slides_tex.md` — тексты в удобном для вычитки виде.
- `shots/` — исходные скриншоты и четыре кропа для баннеров.
- `build_slides.sh` — рендер master 2000×2000 и upload 1000×1000.

## Сборка

```bash
./build_slides.sh
```

Результат:

- `out/ru/slide-XX.png` — 2000×2000;
- `out/ru/upload/slide-XX.png` — 1000×1000 для Addons Marketplace.

Скрипт использует headless Chrome и ImageMagick. Шрифты загружаются локально из `set_demo/views/fonts`.

Скриншоты сняты с локального стенда PrestaShop 9.0.0. Секретный cron-токен на кадре `shot9.png` заменён на `HIDDEN`.
