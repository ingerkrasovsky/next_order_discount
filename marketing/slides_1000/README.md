# Слайды 1000×1000 для Next Order Discount

Компактный вариант набора из `../slides`, подготовленный для прямой загрузки на Addons Marketplace.

## Сборка

```bash
./build_slides.sh
```

Скрипт рендерит каждый слайд в 4000×4000 и уменьшает до 1000×1000 через Lanczos.
Результат: `out/<lang>/slide-01.png` … `slide-14.png`.

Языки: `ru` (источник), `en`, `fr`, `de`, `pl`, `es`. Без аргументов собирается только `ru`:

```bash
./build_slides.sh ru en fr de pl es
```

Тексты берутся из `../slides/translations.js` — один файл на оба билдера.
Переключатель языка — в панели сверху; артборд фиксированный 2000×2000,
поэтому держите заголовок в 2 строки, а пояснение — в 3.

Кадры лежат в `shots/`. Шрифты загружаются локально из `set_demo/views/fonts`.
